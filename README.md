## 🚀 하이브리드 실행 모드

### 1. 구글 스프레드시트 연동 모드 (GAS)
- 구글 시트와 연동되어 여러 작품 시트(`분석텍스트_작품명`)를 동적으로 불러오고 분석합니다.
- **배포 방법**:
  1. 구글 스프레드시트 열기 → **확장 프로그램 → Apps Script**
  2. `Code.gs` 내용 붙여넣기
  3. `index.html` 파일 생성 후 내용 붙여넣기
  4. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자)

### 2. 브라우저 단독 실행 모드 (오프라인 / GitHub Pages)
- 구글 시트가 연결되지 않아도 `index.html`에 내장된 기본 데이터(**황순원 〈소나기〉**, **김유정 〈동백꽃〉**, **불용어 610단어**, **감정어휘 19,819단어**)를 바탕으로 브라우저 내장 자바스크립트 엔진이 100% 동일하게 초고속 마이닝을 수행합니다.
- `index.html` 파일을 더블 클릭하여 크롬/엣지/웨일 브라우저에서 바로 실행할 수 있습니다.

### 3. 나만의 CSV 파일 업로드
- 어떤 소설/문학 작품이든 4컬럼 CSV 파일로 드래그 앤 드롭하면 즉시 10개 탭 전체에서 분석됩니다.
- **CSV 형식**: `문장번호,원본문장,형태소 전처리 문장,소설 구성 단계`

- **프론트엔드**: HTML5, CSS3 (CSS Variables & Flex/Grid), Vanilla JavaScript (ES6+)
