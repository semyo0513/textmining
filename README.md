## 🚀 하이브리드 아키텍처

```
[ GitHub Repository / GitHub Pages (index.html) ]
                   │
                   ▼ (fetch / JSONP)
[ Google Apps Script Web API (Code.gs) ] ──► [ Google Sheets (작품 데이터) ]
```

### 1. 구글 스프레드시트 연동 (GAS Web API)
- GitHub에 배포된 `index.html`에서 GAS Web API URL(`https://script.google.com/macros/s/AKfycby778Q2x0u4yJaM84lIDTJCCbr6nEUe2c52Hl3-WV2bMmVfUAkG0B1zffF3pVk2VFNkoA/exec`)을 호출하여 구글 시트의 작품 목록과 형태소 데이터를 실시간으로 가져옵니다.
- **GAS 배포 방법**:
  1. 구글 스프레드시트 열기 → **확장 프로그램 → Apps Script**
  2. `Code.gs` 코드를 복사하여 붙여넣기
  3. **배포 → 새 배포 (또는 배포 관리 → 새 버전 배포)**
  4. 유형: **웹 앱**, 다음 사용자 권한으로 실행: **나**, 액세스 권한: **모든 사용자 (Anyone)**
  5. 배포 완료 후 생성된 웹 앱 URL 확인

### 2. 브라우저 단독 실행 모드 (오프라인 / 기본 작품 내장)
- 구글 시트가 연결되지 않아도 `index.html`에 내장된 고품질 데이터(**황순원 〈소나기〉**, **김유정 〈동백꽃〉**, **불용어**, **감정어휘 19,819단어**)를 바탕으로 브라우저 자바스크립트 엔진이 100% 동일하게 분석을 수행합니다.

### 3. 나만의 CSV 파일 업로드
- 어떤 소설/문학 작품이든 4컬럼 CSV 파일로 드래그 앤 드롭하면 즉시 10개 탭 전체에서 분석됩니다.
- **CSV 형식**: `문장번호,원본문장,형태소 전처리 문장,소설 구성 단계`
