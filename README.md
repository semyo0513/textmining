# 📚 텍스트마이닝 대시보드

> 창순기획 | 삼현여자중학교  
> Google Apps Script 기반 한국어 소설 텍스트마이닝 웹앱

-----

## ✨ 주요 기능

|탭           |기능                                 |
|------------|-----------------------------------|
|📊 **개요**    |전체 통계, 구성단계별 문장 수, 감정 흐름 타임라인      |
|☁️ **빈도분석**  |워드클라우드 (품사 필터 · 단어 체크박스), 빈도 순위표   |
|🔗 **연관어**   |키워드 검색 → D3 포스 레이아웃 네트워크           |
|🕸️ **전체네트워크**|소설 전체 공출현 네트워크 (단클릭=강조, 더블클릭=원문 팝업)|
|💙 **감정분석**  |긍/부/중립 비율, 문장별 감정 흐름, 감정어 클라우드     |
|🎭 **인물감정**  |사용자 직접 입력 인물 감정 분석 · 비교 차트         |
|📈 **핵심어**   |구성단계별 TF-IDF 시각화 (중학생 친화적)         |
|📖 **이북리더**  |원본 소설 전문 뷰어 (구성단계 · 감정점수 태그)       |

## 📊 구글 시트 구조

|시트명        |컬럼                              |
|-----------|--------------------------------|
|`감정어휘`     |어휘, 감정점수                        |
|`불용어`      |어휘                              |
|`분석텍스트_소나기`|문장번호, 원본문장, 형태소 전처리 문장, 소설 구성 단계|

- `분석텍스트_` 접두어 시트를 여러 개 만들면 **다중 작품 분석** 가능

-----

## 🚀 배포 방법

1. 구글 시트 열기 → **확장 프로그램 → Apps Script**
1. `Code.gs` 내용 붙여넣기
1. `index.html` 파일 새로 만들어 내용 붙여넣기
1. **배포 → 새 배포 → 웹 앱**
- 실행 계정: 나
- 액세스: 조직 내 모든 사용자 (또는 모든 사용자)
1. 배포 URL 복사 → 브라우저에서 접속

## 📂 CSV 업로드 기능

구글 시트 없이도 CSV 파일을 직접 업로드하여 분석 가능합니다.

**CSV 형식** (4컬럼):

```
문장번호,원본문장,형태소 전처리 문장,소설 구성 단계
1,소년은 개울가에서 소녀를 보았다.,소년 개울 소녀 보다,발단
2,소녀는 물장난을 하고 있었다.,소녀 물장난 있다,발단
```

앱 시작 화면에서 **CSV 양식 다운로드** 버튼으로 템플릿 받기 가능.
